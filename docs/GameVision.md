Crystalbound Vision Document
1. The Core Philosophy

This is the most important section.

It should answer:

What is Crystalbound?

For example:

Crystalbound is an exploration-first magical RPG.
Curiosity is the primary gameplay loop.
Progression exists to encourage exploration.
Every feature should make the player want to explore one more area.
The world should feel alive, mysterious and constantly changing.
Players should create their own stories through discovery.

Every future feature should be evaluated with one question:

Does this make the player more curious?

If the answer is no, reconsider it.

2. Design Pillars

These should never change.

Exploration

Players should constantly discover new things.

Not because a quest marker tells them.

Because something catches their attention.

Mystery

Never explain everything.

Questions are more valuable than answers.

Players should wonder:

"What is that?"

"Why is this here?"

"Can I interact with this?"

Rewarding Curiosity

Curiosity should always pay off.

Finding hidden areas should matter.

Secrets should matter.

Exploration should matter.

Living World

The world shouldn't wait for the player.

Things happen.

Animals move.

Butterflies fly somewhere.

NPCs travel.

Magic changes.

Weather changes.

Events happen.

Progression

Players become stronger because they explored.

Not because they stood AFK.

9. Story Philosophy

Story should never interrupt gameplay.

Instead it should enhance exploration.

Small discoveries.

Environmental storytelling.

Ancient ruins.

Books.

NPC conversations.

Cutscenes only when deserved.

10. Player Inner Dialogue

One of my favorite ideas.

The player occasionally talks to themselves.

Not tutorials.

Thoughts.

Examples

"I wonder where that butterfly is going..."

"This crystal feels different..."

"I should ask the wizard..."

"I've never seen magic like this."

"Something isn't right..."

"I should remember this place."

This subtly guides exploration.

11. NPC Philosophy

NPCs should feel alive.

They move.

Travel.

Sleep.

Remember things.

Appear during seasons.

Unlock after discoveries.

Not just stand still forever.

12. Quest Philosophy
