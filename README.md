# Crystalbound

Crystalbound is a Roblox adventure RPG focused on exploration, mining, crafting, RNG-based discoveries, and progression.

Players explore mysterious worlds, mine rare materials, discover powerful crystals, craft unique equipment, complete missions, and build their collection.

## Project Status

Currently in early development.

Current Phase:

- Collection
- Fair F2P Growth

## Architecture

Crystalbound uses a modular service-oriented architecture designed for scalability.

Main systems:

- Services
- Managers
- Controllers
- Configurations
- Shared Modules
